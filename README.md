# First Game in Unreal 

## Game Overview
This game is a simple platformer building off of my [First Hour of Unreal](https://github.com/Haywinkler05/First_Hour_Of_Unreal) project. It has a very simple game loop of reaching the end of the level before the timer reaches 0, and will have some small obstacles and things along the way

## Learning Objectives
- Make a fully polished small game in Unreal
- Work more with blueprints to try and create game mechanics
- Creating a fully polished game

## Tutorial
For this project I am continuing the tutorial on the official [Unreal Documentation](https://dev.epicgames.com/documentation/unreal-engine/your-first-game-in-unreal-engine) 

## Future Goals
- Create a full game from start to finish in Unreal
- Integrate both C++ and scripting
- Follow *The Beginners Guide to Unreal Engine*
